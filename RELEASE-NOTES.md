# OG Mastering 1.0.0 — Windows x64

Download **OG-Mastering-1.0.0-win-x64.exe** and double-click it. No separate FFmpeg, Python, Node or model setup is required. The app extracts its bundled files under your Local AppData folder on first launch; allow time for the progress window to finish. Later launches reuse the extracted files.

Requires Windows 10/11 x64 with the Windows-included .NET Framework 4.8 and Windows PowerShell 5.1. The EXE is unsigned; it has no publisher certificate. Administrator access is not needed for normal use. Allow roughly 1 GB of available space for the extracted runtime/model and temporary processing files, plus space for your songs and exports.

- Simple and Advanced modes; 58 genre presets, including Dark Rap and Dark Country.
- Local import analysis and optional genre/vocal suggestions from the bundled CLAP model.
- EQ, cleanup, stereo, dynamics and mastering controls.
- WAV, MP3 320 kbps, or both; batch exports and reference tone matching.
- Persistent progress panel and recent activity.

Genre/vocal results are suggestions. Review them before applying settings. Model inference has been verified with generated audio; accuracy on individual Suno tracks varies. Some advanced processors remain explicitly marked unavailable in the UI.

**Files:** the Windows EXE, SHA-256 checksums, and the corresponding FFmpeg source archive. App source is available at the release tag. Third-party notices are included inside the extracted application.
